💡Objective
MedTech Industries, a fictional healthcare startup preparing for its IPO, needed to assess whether its processes and IT controls would meet Sarbanes-Oxley (SOX) compliance requirements. As part of PwC's Cybersecurity Consulting team, I worked through a full engagement: identifying control gaps, testing control effectiveness, and reporting findings to a compliance leader.

📍Task 1 — Risk Assessment:
Reviewed MedTech's Procure-to-Pay (P2P) Standard Operating Procedure and identified control gaps against SOX expectations, including:

🔹Purchase requisitions auto-approved with no independent review
🔹Lack of a three-way match (PO, goods receipt, invoice) before payment
🔹Segregation of duties violation — the same person could source a vendor and sign the payment check
Weak, informal user access provisioning for the purchasing system

Wrote a client-facing summary email outlining risks, gaps, and follow-up questions.

📍Task 2 — SDLC Walkthrough:

Prepared for and supported a live walkthrough meeting with MedTech's IT manager to review the payroll system's Software Development Life Cycle (SDLC), comparing it against NIST's SDLC framework. Identified gaps including a missing Disposal/Decommission phase in documentation and a lack of design reviews performed before systems go live, and asked targeted follow-up questions to confirm and clarify each gap in real time.

📍Task 3 — ITGC Test of Design and Operating Effectiveness:

Tested two change management controls for MedTech's CorpLaw system using real evidence (change request forms, user access lists):

🔹Control 1.2 (Emergency Changes): Found that an emergency change was approved by the requestor himself instead of the required IT Director — a control exception.
🔹Control 1.3 (Segregation of Duties): Found a user with access to both the Developer and Implementer roles simultaneously — a segregation of duties violation.

Both findings matched PwC's own professional benchmark answers.

📍Task 4 — Executive Summary:

Distilled the week's findings into a single, board-ready slide for MedTech's Compliance Program Manager, pairing each issue with a clear, actionable recommendation — balancing enough detail to be useful with the discipline to keep it to one slide.

💡Key Takeaway:
SOX and ITGC work is evidence-based, not just a policy review. A control can look fine on paper and still fail in practice — which is exactly what independent testing against real evidence is designed to catch. Every recommendation paired an immediate fix with an ongoing review control, since the goal isn't just fixing today's failure but catching the next one before it happens.
